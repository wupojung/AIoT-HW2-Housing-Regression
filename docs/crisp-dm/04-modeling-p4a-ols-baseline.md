# CRISP-DM Phase 4 — P4-A：全特徵未懲罰 OLS 基準模型（Issue #17）

## 1. 範圍與資料隔離

- 僅使用 Phase 3 外層 80/20 切分（seed 42）之 **1,168 筆開發訓練列**。切分成員以列索引重現，與 `split_labeled_dataset` 的排列完全一致；保留集索引不回傳、不保存。
- 讀檔時逐行串流，只對開發成員行做 CSV 解析；**292 筆封存保留集**之行略過、不解析，**1,459 筆 Kaggle 測試集**完全不開啟。
- `Id` 排除於 X，`SalePrice` 只作為 y。未計算或使用任何 Holdout / Test 指標。
- 公開輸出不含原始列或逐列預測；成員與折分只以 SHA-256 摘要公開。含 OOF ID、實際目標與預測值的檔案只寫入被忽略的 `local/`。

## 2. 方法與重現

1. **交叉驗證**：在 1,168 筆開發列上使用 `sklearn.model_selection.KFold(n_splits=5, shuffle=True, random_state=42)`。折大小為 234/234/234/233/233；折分配摘要為 `7c9f1d00eb74d8a281ba41ed47d5ebbdbffa0513b4bb778b70d1571735ad6463`。
2. **折內前處理**：每折建立全新 `AmesDataPreparationPipeline`，只在該折訓練列上 `fit`，驗證列只 `transform`，不重新擬合。Phase 3 語意未修改；中位數、眾數與類別水準皆為折內學得，因此各折特徵數不同，不強制固定欄數。
3. **模型**：所有折內轉換欄位加截距，以 `numpy.linalg.lstsq`（SVD、最小範數解）求未懲罰最小平方解；不刪欄、不改 one-hot 編碼。每折記錄秩、零化度、奇異值、有效條件數、容差及各階段耗時，並彙總平均與樣本標準差（ddof=1）。
4. **產物**：私有 local JSON 保存 fold assignments、奇異值與逐列 OOF 記錄（Id、fold、實際 SalePrice、預測 SalePrice），可用來獨立重算驗證指標；public JSON 只保存彙總與安全中繼資料，不含逐列內容。

此命令需要本機忽略路徑中的 `local/datasets/train.csv`。輸出目錄應使用新的唯一 `local/` 路徑，以保留既有實驗產物；以下時間戳請每次執行都換成未使用過的值：


Runner 只解析外層切分選出的開發列；Holdout 行只略過、不解析，且不開啟 Competition Test。Public summary 可供審閱；local JSON 含逐列 OOF 和其他私有中繼資料，不得提交或公開。

## 4. 解讀與限制

- **秩不足為預期**：完整 one-hot 類別欄加截距會造成線性相依；係數是最小範數解，**不可解讀為特徵重要性**。
- 訓練與驗證表現有差距，折間指標也有變異；此全特徵 OLS 僅作為後續正則化／特徵選擇的對照基準，不是最終模型。
- 結果僅來自開發集內部 CV，未觸及封存保留集或 Kaggle 測試集，不代表最終泛化表現。
- CSV 讀取按實體列略過，假設欄位不含跨行引號；若開發列欄數不符即中止。
