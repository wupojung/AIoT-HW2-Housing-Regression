# CRISP-DM Phase 4 — P4-A：全特徵未懲罰 OLS 基準模型（Issue #17）

## 1. 範圍與資料隔離

- 僅使用 Phase 3 外層 80/20 切分（seed 42）之 **1,168 筆開發訓練列**。切分成員以「列索引」重現，與 `split_labeled_dataset` 之排列完全一致；保留集索引不回傳、不保存。
- 讀檔時逐行串流，僅對開發成員行做 CSV 解析；**292 筆封存保留集**之行直接略過不解析，**1,459 筆 Kaggle 測試集**完全不開啟。
- `Id` 排除於 X，`SalePrice` 只作為 y。未計算或使用任何 Holdout / Test 指標。
- 公開檔不含原始列、逐列預測或本機路徑；成員與折分只以 SHA-256 摘要公開。

## 2. 方法

1. **交叉驗證**：在 1,168 筆開發列上做 seed 42 打亂之 5 折 CV（折大小 234/234/234/233/233）。
2. **折內前處理**：每折建立全新 `AmesDataPreparationPipeline`，只在該折訓練列上 `fit`，驗證列只 `transform`（不重新擬合）。Phase 3 語意未修改；中位數、眾數與類別水準皆為折內學得，因此各折特徵數不同（241–246），不強制 248 欄。
3. **模型**：所有折內轉換欄位＋截距，以 `numpy.linalg.lstsq`（SVD、最小範數解、預設 `rcond` 容差 `max(n,p)·eps·σ_max`）求未懲罰最小平方解；不刪欄、不改 one-hot 編碼。
4. **紀錄**：每折 RMSE、R²、特徵數與名稱、秩／零化度、奇異值、有效條件數、容差、各階段耗時；彙總平均與標準差（ddof=1）。

重現指令（輸出寫入被忽略之 `local/`）：

```text
python tools/modeling/run_p4a_ols_cv.py --data-dir <local>/datasets --output-dir <local>/research/phase4-p4a
```

## 4. 解讀與限制

- **秩不足為預期**：每個名目欄位都完整 one-hot（無參考類別）且加截距，各組虛擬變數和等於截距欄；再加上結構指標與對應 one-hot／序位欄的共線，以及折內稀有類別全為 0 的欄，使零化度達 33–37。
- **係數不唯一**：最小範數解只是無限多組等價解之一，**係數不可解讀為特徵重要性**；預測值則在可識別子空間內唯一。
- 訓練與驗證差距大、折間變異高（第 2 折 R² 僅 0.49），顯示全特徵 OLS 有過擬合，並對極端值與驗證折內未見類別（每折 2–7 個）敏感。這是作為後續正則化／特徵選擇之對照基準，而非最終模型。
- 本結果僅為開發集內部 CV 估計，未觸及封存保留集或 Kaggle 測試集，不代表最終泛化表現。
- 讀檔採逐行略過，假設 CSV 無跨行引號欄位（Ames 訓練檔成立）；若欄數不符即中止。
