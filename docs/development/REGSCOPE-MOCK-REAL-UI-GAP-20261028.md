## Root cause

The Mock and Real pages use two different rendering paths. The Mock path has phase-specific analysis selectors, stacked-stage components, model/evaluation panels, and interaction state. The Real path routes every Phase 1–6 request through `renderReferencePackagePhase`; Phase 2 maps every analysis to a full card, Phase 3 lists stage totals, Phase 4 prints a raw parameter object and fold table, Phase 5 prints all chart cards and technical identifiers, and Phase 6 prints raw model metadata. Thus the main cause is a **RENDERER GAP**, with a thin/no phase-specific adapter between the package objects and existing visual components. The current package is not missing all of the data needed for a better presentation.

A smaller set of genuine data gaps remains. Missingness and field summaries are encoded inside long `finding` strings; Phase 2 has no structured table reference or target-bin table. Phase 3's original-type contribution to the 248 encoded dimensions has no public lineage mapping, so that chart must remain unavailable/neutral. Phase 4 exposes one fixed Lasso→OLS configuration and CV metrics, not a set of comparable models or a public selected-feature list. Phase 6 has local-only model evidence but no public inference API. These gaps do not justify substituting Mock values.

## Verified numeric bridge for Phase 3

A short read-only script parsed the Phase 2 `field-decisions` text into 81 field/type/action tuples, counted only `include`, asserted 79 predictors, and compared counts against the Phase 3 raw-stage `segments`. It independently parsed all 81 missingness pairs, asserted a common denominator of 1,460 and total 6,965; `MasVnrType` is 8. Results: nominal 26, ordinal 20, discrete 14, continuous 19; exact match to the Phase 3 raw-stage segments. No raw CSV or row-level values were read for this check. The 248 encoded dimensions have no source-type lineage in this package and remain unclassified for visualization.
